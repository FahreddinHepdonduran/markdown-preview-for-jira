Markdown Preview for Jira

Reading

Attachment access

The extension reads your Jira sites only (*.atlassian.net, *.atlassian.com, *.jira.com). Some Jira configurations serve attachment downloads from a different host — a customer S3 bucket, for instance. If a preview fails with “Chrome blocked the download”, turn this on.

Shortcuts

Alt + Shift + M
Open the markdown attachment on this issue
Esc
Close the preview
Ctrl / Cmd + \
Toggle the table of contents

Change the keyboard shortcut at chrome://extensions/shortcuts.
